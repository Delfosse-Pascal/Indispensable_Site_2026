Bienvenue sur le site local Indispensable 2026. Catalogue de logiciels (utilitaires, scripts web, activateurs) et selection musicale. Tout fonctionne hors-ligne dans votre navigateur.

Utilisez les boutons rectangulaires multicolores ci-dessus : changer de theme, rechercher dans le catalogue, ou ouvrir la page Musiques. Le bouton Musiques ouvre une fenetre dediee qui reste ouverte : tant que vous ne la fermez pas, la musique continue meme si vous changez de page. Cliquer plusieurs fois sur le bouton ne recharge pas la fenetre, il la remet juste au premier plan.

Astuces : clic sur une image pour l'agrandir, Echap pour fermer, clic droit "Enregistrer sous" pour sauvegarder tout media.

Aide rapide - Installation des curseurs Windows

  1. Decompressez l'archive de curseurs dans un dossier permanent (ex: C:\Curseurs\).
  2. Ouvrez Panneau de configuration » Souris » onglet Pointeurs.
  3. Selectionnez un pointeur, cliquez "Parcourir...", choisissez le fichier .cur ou .ani correspondant.
  4. Cliquez "Enregistrer sous..." pour memoriser le jeu.
  5. Validez avec OK.

Clic droit "Enregistrer sous" fonctionne sur toutes les images et fichiers audio pour sauvegarder localement.

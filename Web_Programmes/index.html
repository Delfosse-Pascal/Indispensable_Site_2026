Mode d'emploi

Visionner une capture : cliquez sur l'image pour l'agrandir. Pressez Échap ou cliquez en dehors pour fermer.

Sauvegarder l'aperçu : clic droit » "Enregistrer l'image sous...". Format JPG ou PNG selon le programme.

Télécharger l'archive complète : clic sur le bouton vert, ou clic droit sur celui-ci » "Enregistrer la cible sous...". Le fichier .rar / .zip se décompresse avec 7-Zip, WinRAR ou l'utilitaire intégré de votre système.

Installer un programme : décompressez l'archive, puis lancez l'exécutable (généralement Setup.exe ou similaire). Suivez les instructions à l'écran.

Installation des curseurs (curseurs Windows)

  1. Téléchargez l'archive contenant les fichiers .cur ou .ani.
  2. Décompressez-la dans un dossier permanent (ex. C:\Curseurs\).
  3. Ouvrez le Panneau de configuration » Souris » onglet Pointeurs.
  4. Sélectionnez un pointeur, cliquez "Parcourir...", choisissez le fichier .cur ou .ani correspondant.
  5. Validez avec OK. Pour sauvegarder votre jeu : cliquez "Enregistrer sous...".
